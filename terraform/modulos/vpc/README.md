Este módulo crea la Virtual Private Cloud (VPC) que sirve como red principal del Sistema de Inventario.
Aísla los recursos en un entorno seguro dentro de AWS y permite la comunicación controlada entre los distintos componentes (EC2, RDS, ALB, etc.).

Incluye la configuración de subredes públicas y privadas, tablas de ruteo, Internet Gateway y NAT Gateway para asegurar la conectividad adecuada entre los servicios internos y externos.
