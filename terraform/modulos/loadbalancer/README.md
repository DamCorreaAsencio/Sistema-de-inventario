# Modulo Application Load Balancer (ALB)

Este módulo implementa un Application Load Balancer (ALB) en AWS, encargado de distribuir el tráfico entrante entre las instancias EC2 del Sistema de Inventario.
El ALB actúa como intermediario entre el API Gateway y las EC2, asegurando balanceo eficiente, alta disponibilidad y comunicación segura mediante HTTPS.
